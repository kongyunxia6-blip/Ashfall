Ashfall 核心玩法与特殊 Block 系统 V1

版本：V1
用途：核心玩法基线 / 后续 Unity 开发与 WorkBuddy 任务拆分依据

第一部分：《Ashfall 核心玩法总纲 V1》

1. 游戏核心定位
《Ashfall》是一款末日废土背景下，以地下挖掘、资源搜集、风险撤离、装备成长和古文明探索为核心的 2D 横版探索游戏。
核心驱动力：“下面到底还有什么？我能不能再往下一层？”
核心主题：“向下挖掘失落文明，向上重建最后的城市。”

2. 核心循环
地表据点准备 → 进入地下 → 挖掘岩层 / 规划路线 → 发现矿物 / 洞穴 / 遗迹 / 特殊事件 → 背包逐渐装满 + 能源逐渐消耗 → 决定继续深入或撤离 → 返回地表 → 出售 / 制造 / 修复 / 升级 → 获得新的挖掘能力 → 突破以前无法进入的区域 → 继续向更深处探索。
核心体验不是“把所有砖挖完”，而是持续制造“再挖一点”的诱惑与风险决策。

3. Block 破坏基础规则
所有标准可破坏 Block：完整 → 裂纹1 → 裂纹2 → 裂纹3 → 崩碎 → 消失。
不存在“空洞”Sprite 状态。崩碎结束后 Block 直接消失，显示后方连续地下岩层背景。裂纹是视觉阶段，不代表所有 Block 固定需要四次攻击。

4. 单格挖掘原则
任何采矿工具、任何等级、任何技能或模块，一次挖掘永远只作用于 1 个 Block。
禁止横向三格、纵向三格、3×3 范围破坏、后期范围清屏。
工具成长重点：挖掘速度、可处理岩层硬度、能源效率、特殊 Block 处理能力、环境交互能力、信息获取能力。
特殊 Block 自身引发的坍塌、爆炸、电路变化等环境连锁效果不属于工具范围挖掘。

5. 普通岩层
建议：松软土层、砂岩、普通岩、坚硬岩、深层黑岩。区别主要体现在挖掘耐久、能源消耗、工具最低能力。
当前区域正常装备应让大部分普通 Block 保持约 2～4 次有效挖掘完成。旧装备进入新区域可明显变慢；升级后重新恢复流畅节奏，而不是无限堆 HP。

6. 矿物与资源
第一阶段约 8～10 种以内。基础：铁、锡、铜；中高级：铂金、绿宝石、红宝石、钻石；世界观资源可考虑 Ash Crystal（灰烬晶体）。
矿物不能全部只是不同价格的钱，应承担不同制造、升级、修复或研究用途。

7. 矿脉与扫描
矿脉隐藏在普通岩层中形成自然矿脉，避免规则大方块。扫描器提供隐藏矿物、异常区域、危险 Block、遗迹结构等信息，但不自动挖掘。

8. 装备成长
主采矿工具负责基础挖掘效率、可处理硬度、能源效率、基础耐热/稳定能力；无论等级如何始终只破坏 1 格。
功能模块负责玩法能力扩展：冷却、稳定、绝缘、共振、扫描、遗迹解析等。建议模块槽有限，促使玩家下矿前进行配置。

9. 背包系统
有限格数 + 重量/容量约束；普通矿物可堆叠，大型遗物可占更多空间。服务于“继续深入还是撤离”的风险选择。

10. 能源系统
不采用传统饥饿值，使用能源驱动钻机、扫描、照明、特殊模块和机械设备。能源下降与背包、生命共同形成撤离压力。

11. 撤离与失败
越深入资源价值和风险越高。死亡不清空永久装备、永久升级和关键剧情道具，可损失部分本次资源，并可考虑遗失背包 / Lost Cargo 机制。

12. 地下纵向世界
示例：地表；0～100m 废土浅层；100～300m 废弃矿区；300～600m 地下机械城；600～900m 古代遗迹；900～1200m 晶体深渊；更深处 Ash Core。深度本身作为重要进度反馈。

13. 地下特殊空间
可包括废弃矿工营地、机械维修室、地下列车站、晶体洞穴、废弃实验室、地下湖、巨型机械残骸、古代祭坛、青铜墓室、隐藏商人/幸存者区域。目标是制造“下一堵墙后面是什么？”

14. 古文明探索
工业废墟 → 旧时代矿井 → 异常青铜构件 → 巨型青铜文明遗物 → 地下遗迹 → 更深层文明真相。可吸收古蜀青铜文明神秘感，但形成 Ashfall 自己的原创文明体系。

15. 地表据点与聚落复兴
机械工坊、精炼厂、商人、研究所、升降机、居民区/任务 NPC。资源带回地表后用于修复设施、恢复供电、解锁工具、快速交通和遗物分析，让玩家成长与城市成长绑定。

16. 任务方向
优先调查异常信号、寻找指定矿物/失踪矿工、修复地下设施、恢复升降机供电、寻找遗迹部件、抵达指定深度、分析未知文明结构。

17. 战斗定位
优先级：挖矿 > 探索 > 成长 > 战斗。敌人主要承担环境危险与探索压力，不把游戏做成刷怪为核心的横版 ARPG。

18. 第一版 MVP
1 个地表据点、1 个地下区域、基础普通岩层、约 6 种基础矿物、1 套主采矿工具、背包、能源、返回地表、资源结算、1 条工具升级线、1 个隐藏洞穴、1 个小型遗迹、少量特殊 Block。
验证循环：挖下去 → 找东西 → 再挖一点 → 背包/能源形成压力 → 撤离 → 升级 → 再次下矿。

第二部分：《Ashfall》特殊 Block 系统 V1

1. Block 四大类别
普通岩层：构成地图与控制基础挖掘节奏。
矿物 Block：提供资源、制造材料和经济价值。
特殊 Block：改变挖掘方法、路线规划和风险判断。
遗迹 Block：承担探索、解谜、剧情和能力门。
核心问题：“应该怎么挖？”“现在该不该挖？”“挖掉以后会发生什么？”

2. 承重岩
核心玩法：改变地图结构。可正常单格破坏；被破坏后关联松散岩层可能失去支撑，触发局部坍塌。坍塌既可能危险，也可能打开新路线。第一版不要求特殊装备。

3. 爆裂岩
核心玩法：风险控制。红橙色发光裂隙；破坏过程中进入危险状态。错误操作可触发 Block 自身爆裂，伤害玩家、触发环境对象或引发其他爆裂岩连锁。属于环境效果，不是玩家范围挖掘。稳定模块可降低风险。

4. 共振晶体
核心玩法：节奏挖掘。攻击后产生发光/声音反馈，后续攻击存在共振时间窗口；正确节奏推进裂纹，错误节奏可能恢复一个阶段。共振模块扩大操作窗口但不自动开采。

5. 高温岩
核心玩法：装备能力门。黑色火山岩 + 暗红熔光；早期持续攻击导致钻机过热，获得冷却模块后正常处理。用于地热层、早期路线阻挡和回访旧区域。

6. 导电矿岩
核心玩法：不是所有矿都应该挖。自身具有资源价值，同时可以传递电力。破坏可能切断电路、关闭机械门/危险机关或改变区域状态。绝缘模块允许安全处理，但不替玩家决定是否破坏。

7. 遗迹封印块
核心玩法：世界观探索与能力门。早期普通工具无法有效处理，获得遗迹解析能力后才能理解并处理部分封印结构。可破坏遗迹 Block 仍遵循标准破坏流程；祭坛、青铜雕像、核心装置、剧情机关、重要文明遗物等不可直接破坏。

8. 六种特殊 Block 职责
承重岩：挖掉会发生什么？
爆裂岩：现在挖安全吗？
共振晶体：我能否正确操作？
高温岩：装备是否准备好？
导电矿岩：我到底该不该挖？
遗迹封印块：这里隐藏着什么？

9. 特殊 Block 区域化
废弃矿井：承重岩 + 基础矿物。
地热层：高温岩 + 爆裂岩。
晶体洞穴：共振晶体。
地下机械城：导电矿 + 电力机关。
古文明遗迹：遗迹封印块 + 古文明机关。
特殊 Block 不平均随机撒满矿洞，而以区域主题组织。

10. 第一版特殊 Block MVP
第一版 Demo：承重岩、爆裂岩、高温岩 + 普通岩层 + 基础矿石。
第二阶段：共振晶体、导电矿岩、遗迹封印块。
第一版首先验证单格挖掘是否顺畅、有反馈、有路线决策。

第三部分：当前锁定设计规则

1. 所有采矿工具始终只作用于一个 Block。
2. 不设计横三格、竖三格、3×3 等装备范围破坏能力。
3. 标准 Block：完整 → 裂纹1 → 裂纹2 → 裂纹3 → 崩碎 → 消失。
4. 不存在“空洞”Sprite 状态。
5. Block 消失后显示后方连续地下背景。
6. 装备成长主要依靠效率、能源、特殊 Block 处理能力与环境交互。
7. 特殊 Block 应改变玩家决策，而不只是增加 HP。
8. 不是所有石块都应该被玩家无脑挖掉。
9. 特殊 Block 以区域主题方式出现，不平均随机铺设。
10. Ashfall 的核心优先级：挖矿 > 探索 > 成长 > 战斗。
