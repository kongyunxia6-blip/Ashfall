# DEV-017 玩家角色表现 V1

## 目标

把已经导入的 Spine 采矿人从“资源可播放”推进到正式游戏角色表现层。角色表现只读取现有权威玩法状态，不改写移动、碰撞、采矿、燃料、货舱或经济逻辑。

## 权威状态与动画映射

| 表现状态 | 权威来源 | Spine 动画 | 循环 |
|---|---|---|---|
| 待机 | 无移动、无采矿、无飞行 | `idle` | 是 |
| 行走 | `Grounded` 且水平速度超过阈值 | `walk` | 是 |
| 挖矿 | `MiningFeelController.IsMining` | `skili01` | 按住期间循环 |
| 飞行 | `DrillVehicle.Jetting`，或离地且存在有效速度 | `skill02` | 是 |

状态优先级：挖矿 > 飞行 > 行走 > 待机。

## V1 范围

1. 正式场景和场景 Builder 都生成同一套玩家层级：
   - `Player`：Rigidbody2D、Collider2D、DrillVehicle、MiningFeelController。
   - `Player/PlayerSpineVisual`：SkeletonAnimation、PlayerSpineVisual、MeshRenderer。
2. 角色视觉比例、脚底位置与碰撞体中心分离配置。
3. 水平移动和水平挖矿根据目标方向镜像；停止时保留最后朝向。
4. 动画切换加入短混合时间，避免硬切抖动。
5. 运行时缺动画或资源时只报告一次明确错误，并回退到 `idle`。
6. 场景重建幂等，不生成第二个视觉节点、第二个 SpriteRenderer 或第二个 MiningFeelController。
7. 为受击、落地、死亡预留表现入口，但 V1 不伪造不存在的 Spine 动画。

## 不在本阶段修改

- DrillVehicle 的移动数值、燃料和载重公式。
- DigGrid、矿脉、地层与经济配置。
- Spine 原始骨骼、网格和美术帧内容。
- 新增受击、死亡动画资源。

## 验收门禁

1. Unity 6.3.21f1 编译完成，Console 0 Error / 0 Exception。
2. SkeletonData、Atlas、Material 引用完整，运行时 MeshRenderer 有有效网格。
3. Play 中验证 `idle → walk → mining → flying → idle`。
4. 左右移动与左右挖矿镜像正确，竖直挖矿不随机改变朝向。
5. 玩家碰撞体、世界坐标和相机跟随不受视觉缩放影响。
6. 重建 WorldGenV1 后玩家视觉节点唯一。
7. DEV-016 回归 19/0，DEV-015 经济回归 38/0。
