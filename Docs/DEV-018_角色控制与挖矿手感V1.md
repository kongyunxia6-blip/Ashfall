## 目标闭环
`Surface → 自动开始 Run → 行走进入矿口 → 下潜 → 连续单格挖矿 → 跨地层采集 → 带货返航 → SellTerminal 出售 → Run end`

## 核心改动

### 1. 玩家默认运动模式：Hover → Walk（任务书 §1）
- 审阅发现 WorldGenV1 正式玩家默认 `startMode = Hover`（悬浮直驱、永不坠落），无法体现「地面站稳起步 / 走出边缘自然坠落 / 喷气开启稳定返航」的地面手感。
- **改动** `Dev016WorldSceneBuilder.cs`：`vehicle.startMode = DrillVehicle.MovementMode.Walk`，`startJetting = false`（脚踏实地起步，空格开喷气悬浮返航）。
- Walk 模式（Motherload 式）语义：地面 `walkAccel/walkFriction` 行走、走出边缘受引擎重力坠落（`maxFallSpeed` 限速）、空格切力驱动喷气（`hoverAccel/hoverDecel` 惯性对抗）上升横移制动返航。

### 2. 出生点调整：坑口正中 → 坑口右缘外实心地表（任务书 §1「进入矿井」）
- 地形：坑口带 = 网格 `x[center-halfWidth .. center+halfWidth]`（center=24, halfWidth=4 → x20..28），`y≤2` 挖空；两侧地表实心。
- 原出生 `(24, 1)` 恰在坑口开口正上方——Hover 时代可行，Walk 模式会直接坠落穿洞。
- **改动**：出生/重生点设为坑口右缘外第一块实心行0 格上方 `(29.5, 0.36)`：圆心落行-1 地表空气带、脚下行0 实心，**站稳起步、往左一步即进坑口开口坠落**；GameManager.spawnPoint 同步；相机开局对准出生点防瞬移漂移。
- `surfaceSpawnX = center + shaftHalf + 1 = 29`。

### 3. 挖矿控制（任务书 §2）
- 保持 `MiningFeelController → DrillVehicle.TryDigHit → DigGrid` 唯一挖掘路径；严格单格、四方向相邻（`ResolveTarget` 锁格迟滞），**不新增 AoE**。
- 未改动挖掘节奏参数（`attackInterval/hitStop/recovery/breakExtraPause` 已集中公开字段）；装备成长权威倍率入口 `EffectiveMultiplier`（含 `EquipmentProgression.EffectiveDigSpeedMultiplier`）保持。

### 4. Spine 表现联动（任务书 §3）
- 复用 `PlayerSpineVisual` 映射：idle/walk/skili01(挖矿)/skill02(喷气)；优先级 挖矿>飞行>行走>待机。DEV-017 已实现，DEV-018 回归复核其确定性切换。

### 5. 载重返航（任务书 §4）
- 不改 Ore/Equipment/Economy 数值表。载重只按现有规则惩罚向上（`weightClimbPenalty` 施加于 JetMove 上升），下潜/水平不受影响，不破坏燃料与 Run 生命周期（回归 8 断言接线存在）。

### 6. 场景构建器同步（任务书 §5）

## 权威玩法规则落地（任务书 §权威玩法规则 / §状态与输入要求）

### 1. 着地权威门控（`MiningFeelController.TickMining` 顶部）
- 以 `DrillVehicle.Grounded` 为着地权威，`Jetting == true` 一律禁止挖掘。
- 只有 `vehicle.Grounded && !vehicle.Jetting` 才允许锁定目标 / 高亮 / 命中。
- **离地当帧**：`stance gate` 在 `TryDigHit` 之前 `return`，立即清 `CurrentTarget`、关高亮、`IsMining=false`，无任何空中宽限命中。
- 兼容性核验：`Game.unity`（Hover 原型）**无 MiningFeelController**，走旧 `TryManualDig`，不受门控影响；`MiningFeelV1Test` 玩家已是 Walk。其余 probe（Economy/Discovery/Block/AncientRelay）都直接 `TryDigHit(cell)`，不经 MiningFeelController → 不受门控影响。

### 2. 权威朝向 `Facing`（+1 右 / -1 左）
- 新增 `public int Facing { get; private set; } = 1;`，**只由最近一次有效左右输入更新**（`raw.x` 超 `directionDeadZone` 即更新）；S/W 竖直键不改左右朝向，杜绝「按键随机改面」。
- front / frontDown 都相对 `Facing` 判定；`PlayerSpineVisual` 挖矿期朝向改读 `mining.Facing`（规则 10）。

### 3. 前方双格目标解析（`ResolveTarget` 重写）
- `pc = grid.WorldToGrid(身体)`；`front = pc + (Facing,0)`；`frontDown = pc + (Facing,+1)`（网格 y 向下为正）。
- **水平请求（A/D）**：只锁 `front`；`front` 空（空气/崩碎/界外）→ null，**绝不自动改挖 frontDown**（规则 4）。
- **向下请求（S/下）**：`front` 仍实心 → 先锁 `front`（规则 2/3）；`front` 已清空 → 才锁 `frontDown`。
- 正上 / 身后 / 正脚下 / 斜上 / 两格以外天然不在 front/frontDown 集合 → 永不选中（规则 8）。
- W/上、无方向、水平竖直等强歧义 → 无挖掘请求（`currentDir=zero`）。
- 去掉旧 4 方向迟滞锁格（`lockedCell` / `directionSwitchThreshold` / `maxTargetDistance`）：目标由「Facing + 当前实心度」每帧确定性重算；DigGrid 耐久单调递减、实心未崩时同朝向每帧锁同一格，等价稳定锁定且无多格穿透。

### 4. 挖掘节奏与权威路径保留
- 按住连续挖掘、`attackInterval` 门控、hit-stop、break pause、`EffectiveMultiplier`（含 `EquipmentProgression.EffectiveDigSpeedMultiplier`）、严格单格——全部保持。
- 唯一权威路径 `MiningFeelController → DrillVehicle.TryDigHit → DigGrid` 不变。
