## 目标闭环
`Surface → 自动开始 Run → 行走进入矿口 → 下潜 → 连续单格挖矿 → 跨地层采集 → 带货返航 → SellTerminal 出售 → Run end`

## 核心改动

### 1. 玩家默认运动模式：Hover → Walk（任务书 §1）
- 审阅发现 WorldGenV1 正式玩家默认 `startMode = Hover`（悬浮直驱、永不坠落），无法体现「地面站稳起步 / 走出边缘自然坠落 / 喷气开启稳定返航」的地面手感。
- **改动** `Dev016WorldSceneBuilder.cs`：`vehicle.startMode = DrillVehicle.MovementMode.Walk`，`startJetting = false`（脚踏实地起步，空格开喷气悬浮返航）。
- Walk 模式（Motherload 式）语义：地面 `walkAccel/walkFriction` 行走、走出边缘受引擎重力坠落（`maxFallSpeed` 限速）、空格切力驱动喷气（`hoverAccel/hoverDecel` 惯性对抗）上升横移制动返航。

### 2. 出生点调整：坑口正中 → 坑口右缘外实心地表（任务书 §1「进入矿井」）
- 地形：坑口带 = 网格 `x[center-halfWidth .. center+halfWidth]`（center=24, halfWidth=4 → x20..28），`y≤2` 挖空；两侧地表实心。
- 原出生 `(24, 1)` 恰在坑口开口正上方——Hover 时代可行，Walk 模式会直接坠落穿洞。
- **改动**：出生/重生点设为坑口右缘外第一块实心行0 格上方 `(29.5, 0.36)`：圆心落行-1 地表空气带、脚下行0 实心，**站稳起步、往左一步即进坑口开口坠落**；GameManager.spawnPoint 同步；相机开局对准出生点防瞬移漂移。
- `surfaceSpawnX = center + shaftHalf + 1 = 29`。

### 3. 挖矿控制（任务书 §2）
- 保持 `MiningFeelController → DrillVehicle.TryDigHit → DigGrid` 唯一挖掘路径；严格单格、四方向相邻（`ResolveTarget` 锁格迟滞），**不新增 AoE**。
- 未改动挖掘节奏参数（`attackInterval/hitStop/recovery/breakExtraPause` 已集中公开字段）；装备成长权威倍率入口 `EffectiveMultiplier`（含 `EquipmentProgression.EffectiveDigSpeedMultiplier`）保持。

### 4. Spine 表现联动（任务书 §3）
- 复用 `PlayerSpineVisual` 映射：idle/walk/skili01(挖矿)/skill02(喷气)；优先级 挖矿>飞行>行走>待机。DEV-017 已实现，DEV-018 回归复核其确定性切换。

### 5. 载重返航（任务书 §4）
- 不改 Ore/Equipment/Economy 数值表。载重只按现有规则惩罚向上（`weightClimbPenalty` 施加于 JetMove 上升），下潜/水平不受影响，不破坏燃料与 Run 生命周期（回归 8 断言接线存在）。

### 6. 场景构建器同步（任务书 §5）
- 改动集中在 `Dev016WorldSceneBuilder.Build()`，重跑菜单「灰烬之下/DEV-016 搭建：正式地层世界」即得含 Walk 玩家的 `WorldGenV1.unity`；不覆盖 `Game.unity`；保持单相机 / SurfaceHubZone / SellTerminal / 48×640 地层结构。
