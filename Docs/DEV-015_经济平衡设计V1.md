## 1. 核心决策问题 → 设计支点

Issue 8 问，落在现代 DEV 栈的答案：

1. **Cargo 已经很值钱还要深入吗** → 靠「单趟载重上限（重量先到顶）+ 越深越重越贵但单趟可带件数减少 + 返航燃料余量」制造机会成本。Cargo 价值随深度上升，但**收益不是线性**：深层高单价矿单件重、堆叠少 → 重量预算被高单价单件吃紧 → 「这趟满载回去，还是再下去冒更大返航风险」真实成立。
2. **单价高但太重值得占格吗** → 价值密度 valuePerWeight 分层：铁/锡/铜低密度，银/金中，铂金/祖母绿/钻石高密度但单件更重。`HandleTileDug` 已按**价值密度**丢最差换入 → 玩家会为高密度资源放弃低密度堆（铁矿 vs 钻石）。
3. **Fuel 够安全返航吗** → 载重爬升油耗惩罚 `×upwardFuelMultiplier×(1+LoadRatio×weightFuelPenalty)` + 满载返回；深 Run 满载返航的余量显著恶化。EfficientMotor(−15%) 与 FuelTank(上限) 是两条不同维度的解药。
4. **为 Discovery Node 绕路值得吗** → 节点奖励按 region 价值最高的矿种；但绕路消耗燃料 + 载重被占用 → 至少一种配置下「放弃节点直接返航」更优。
5. **深层矿是更值钱还是单位重量更值钱/更稀有/更危险** → 用多维：深层 = **更高价值密度 + 更稀有 + 更重 + 更高硬度门槛 + 风险(坍塌/热/遗迹)** 共同变化（≥3 维），非单乘价。
6. **升级价节奏** → 调 EquipmentCatalog：Lv1 首升约 1 个成功浅层 Run；中段 1~3 Run；高阶需 Mid/Deep 高质量货（浅层刷不出）。
7. **主动丢弃低值资源** → `HandleTileDug` 价值密度替换即机制；验收用 Play 场景复现「铁矿堆被钻石顶掉」。
8. **见好就收节点** → 存在「本趟能安全返航」的满载点；再深入则返航余量转负 → 最优策略是折返，不是挖到硬上限。

## 3. 深度价值曲线 V1（≥3 维共同变化，非单乘价）

| Region | 深度 | 单位重量价值 | 单格价值 | 稀有度/权重 | vein 大小 | 环境/门槛 |
|---|---|---|---|---|---|---|
| Surface | 0..2 | — | — | 无矿 | — | 起点/Hub |
| Shallow | 3..21 | 低 | 低~中 | 铁/锡/铜 密集 | 小(2~4) | 无门槛 |
| Mid | 22..43 | 中 | 中~高 | 铜/银/金 出现 | 中(3~5) | 硬度 2 银/金 |
| Deep | 44..62 | **高** | 高~很高 | 金/铂/祖母绿/钻石/文明 | 大(4~6)但单件重 | 硬度 3~4 + 风险节点 |

四维共同变化：**(1) valuePerWeight↑ (2) valuePerSlot↑ (3) 稀有度(高价值矿权值低→少见) (4) vein 中更有重单件 + 硬度门槛 + Discovery/Ruin 风险**。Shallow 无法成为无限刷钱最优解——因为 Lv1 装备升级到中段后 Shallow 单趟价值增长被载重/返航余量封顶，Mid/Deep 的高密度单件是唯一拉开单趟收益的路径。

## 4. 模拟模型（Editor-only 确定性，不参与 runtime）

输入：region 典型矿脉组成（band 权重抽样）、Cargo capacity/weight cap、Fuel cap、equipment level、路径长度/深度。
输出：expected Cargo value / weight / value-per-weight / Fuel used & remaining / safe-return margin / expected runs to next upgrade。
公式取真实现：
- Fuel：idle 0.5/s；移动 1.1×moveMult；上行 ×2.2×(1+LoadRatio×0.35)；挖掘 +2.0/s。
- 满载惩罚：LoadRatio 影响上行油耗。
- 载重上限：Lv0 24 / Lv1 30 / Lv2 37 / Lv3 45（+CargoRack +6）。
- 格数：6×rows(2..5)。
- 升级成本：见 §6。
